# 🏔️ 景区二消产品搜罗平台 v1.0

搜罗全国/全球景区内二消产品（吃住行游购娱），支持自动抓取、分类浏览、图片视频展示、商家联系方式查询。

---

## 📱 Android 手机安装指南

本平台采用 **PWA（渐进式Web应用）** 技术，无需下载APP商店，通过浏览器即可安装到手机桌面：

### 步骤1：启动电脑端服务
双击运行 `start.bat`，等待后端+前端启动完成。

### 步骤2：手机连接
1. 确保手机和电脑连接在**同一个WiFi**下
2. 查看电脑IP地址（运行 `ipconfig` 命令查看）
3. 手机Chrome浏览器访问：`http://你的电脑IP:5173`

### 步骤3：安装到桌面
1. Chrome浏览器右上角菜单 → **"添加到主屏幕"**
2. 或等待浏览器底部弹出 **"添加到桌面"** 横幅提示
3. 点击"安装"即可

✅ 安装后手机桌面会出现 **"景区投资"** 图标，点击即可像原生APP一样使用！

## 📊 功能模块

### 🔍 产品搜索与浏览
- 瀑布流展示最新产品
- 7大分类 + 20+子分类浏览
- 关键词搜索 + 地区 + 投资区间筛选
- 产品详情：图片画廊、视频、联系方式、投资分析

### 🤖 自动抓取
- 支持平台：B站、抖音、小红书、淘宝、微信公众号、今日头条、行业垂直网站
- 每日定时抓取（早8点全量 + 每6小时高频）
- 手动触发单源/全量抓取
- 去重 + 待审核机制

### 👥 多用户协作
- 管理员：全部权限
- 编辑：添加/编辑产品、管理抓取源
- 观察者：浏览查看

### 📱 PWA 移动特性
- 离线缓存（已浏览产品可离线查看）
- 添加到桌面（全屏体验）
- 下拉刷新、图片懒加载

## 📝 使用流程

1. **双击 `start.bat` 启动服务**
2. **手机浏览器访问**（同WiFi下）
3. **注册账号** → 首个注册用户自动成为管理员
4. **浏览产品** → 首页瀑布流、分类、搜索
5. **配置抓取源** → 添加目标网站，手动/自动抓取
6. **审核产品** → 爬虫抓取的产品默认"待审核"，手动确认后公开
7. **添加到手机桌面** → PWA安装

## ⚠️ 注意事项

- 爬虫功能请遵守目标网站的 robots.txt 和使用条款
- 建议为爬虫设置合理的抓取频率（默认24小时）
- 部分平台（淘宝、小红书等）可能需要定期更新Cookie
- 生产环境部署建议使用 PostgreSQL 替代 SQLite
- 修改 `backend/config.py` 中的 `SECRET_KEY` 以提升安全性
